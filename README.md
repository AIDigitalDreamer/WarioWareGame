# Comic Microgames

A colourful, comic-book-style microgame project made with **Godot Engine**. The game is inspired by fast-paced microgame collections: short challenges, bold visuals, and quick restarts.

> This is an independent fan-inspired project and is not affiliated with or endorsed by Nintendo or the creators of WarioWare.

## Features

- A comic-style title screen.
- A colourful gameplay background with a platform along the bottom edge.
- A custom character sprite.
- A heart icon for the lives/health display.
- A comic-style **GAME OVER** screen.
- A bright, high-contrast art style with bold outlines and saturated colours.

## Built With

- **Godot Engine 4.7.2**
- **GDScript** for game logic, where used.
- PNG artwork for backgrounds, sprites, and UI elements.

## Getting Started

### Requirements

- Godot Engine 4.7.2 or a compatible version of the Godot 4 series.
- The project files, including `project.godot` and the asset folders.
